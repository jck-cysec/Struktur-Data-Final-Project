## 🕹️ Judul Proyek: **NokenzGameStore**

> **"Noken"** adalah tas khas Papua yang memiliki berbagai isi. Filosofinya diadaptasi menjadi toko digital berisi banyak pilihan game dari berbagai genre populer.

NokenzGameStore menawarkan 5 kategori utama:
- 🗺️ **Adventure**
- 🎯 **Action**
- 🛠️ **Simulation**
- ⚽ **Sports**
- 🧙 **RPG**

Sistem penjualan dilengkapi dengan:
- Tampilan yang menarik
- Fitur diskon dinamis:
  - 💸 **Diskon 50%** untuk pembelian 2 game
  - 💸 **Diskon 75%** untuk pembelian lebih dari 2 game

---

## 🔧 Komponen Sistem

### 📊 Tipe Data
- **String**: Nama Pembeli, Kategori, Nama Game  
- **Integer**: ID Pembeli, Harga Game  
- **Double**: Pembayaran, Diskon

### 🧱 Struktur Data
| Struktur     | Fungsi Penggunaan |
|--------------|-------------------|
| `ArrayList`  | Menyimpan transaksi & riwayat pembelian |
| `LinkedList` | Menyimpan daftar pembeli & keranjang |
| `Tree`       | Menyimpan nama game dan hitung jumlah unik |
| `Record`     | Menyimpan data game (sebagai objek) |
| `Searching`  | Mencari game yang dibeli pembeli |
